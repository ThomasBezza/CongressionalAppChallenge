# Rehearsal room — hosted demo

A phone-first browser companion for a hosted ordering-food rehearsal with a willing human partner. Audio stays in an existing call. The app synchronizes host admission, role views, participant-owned time/pause requests, and voluntary retry/leave/end.

Run with Node 24: `node server.mjs`. Run integration checks: `node --test`.

[Hosting instructions](HOSTING.md) · [Repeatable demonstration](DEMO.md)

This public repository contains an app-only deployment snapshot. Personal project and research notes are not included. No recording, speech scores, or clinical-effectiveness claim. Rooms live in server memory for at most one hour and disappear on restart.
